## 2. Mom Test 워크북

### 2.1 페르소나

**UnitConverter 학습자** — Python 실습 과정에서 `UnitConverter.py` CLI를 다루는 중. README 요구사항을 읽고 기본 코드를 실행·검증하는 단계.

### 2.2 인터뷰 답변 (과거 사실)

| # | 질문 요지 | 응답 (과거 사실) |
|---|-----------|------------------|
| 1 | 최근 사용 시점·상황 | **2026-06-11 오후**, README 직후 `meter:2.5` 실행. 출력 `8.2021 feet` vs README `8.2 feet` 불일치. 동일 입력 **3회** → 결과 동일 |
| 2 | 결과가 달랐다면? | **가정 거부** — 실제로는 3회 동일. README 차이 **메모장 기록** |
| 3 | 확인 직후 행동 | 터미널 유지, `feet:8.2` **1회** 입력 → `2.4999875686 meter` 등 출력 후 종료·메모 |
| 4 | 잘못된 값 입력 | `meter:abc` → `Invalid number: abc` / 빈 Enter → `Invalid format…` / `meter:-2.5` → **에러 없이** 음수 변환 |
| 5 | 0·큰 수·긴 소수 | **시도 안 함** — 실제 입력 5종만 (§2.3) |

### 2.3 실제 입력·출력 기록

| 입력 | 출력 |
|------|------|
| `meter:2.5` (×3) | `8.2021 feet`, `2.734025 yard` |
| `feet:8.2` | `2.4999875686 meter`, `2.7333333333 yard` |
| `meter:abc` | `Invalid number: abc` |
| (빈 입력) | `Invalid format. Use unit:value (ex: meter:2.5)` |
| `meter:-2.5` | `-8.2021 feet`, `-2.734025 yard` (차단 없음) |

### 2.4 표면 문제 (금지 — 솔루션 섞인 문장)

- ❌ 「**단위 변환 프로그램**이 필요해요」
- ❌ 「`meter:2.5` 형식으로 **JSON 출력**해 주면 좋겠어요」
- ❌ 「**OCP·테스트 코드**를 넣으면 해결돼요」

### 2.5 진짜 문제 (한 문장)

**README에 적힌 기대(반올림 예시, 음수 차단)와 실제 프로그램 출력·동작이 일치하지 않아, 변환 결과를 믿고 쓰기 전에 같은 입력을 반복 실행하고 직접 잘못된 값을 넣어 검증하는 데 시간을 썼다.**

## 3. Mom Test 증거 3줄

1. `meter:2.5`를 **3회** 실행해 결과 동일 여부를 확인했고, 출력 `8.2021 feet`가 README 예시 `8.2 feet`와 달랐다.
2. `feet:8.2` 실행 후 README와 소수점 차이를 **메모장에 기록**했다.
3. README는 음수 검증을 요구하지만 `meter:-2.5`는 **에러 없이** 변환 결과가 출력됐다.
